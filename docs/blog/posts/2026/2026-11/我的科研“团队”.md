# 我的科研“团队”

OpenBot——开源版的"Grok Bot"，通过管理团队的思想管理多个 Agent，我用 OpenBot 实现了一个科研团队。

<!-- more -->

一人公司的概念在前不久非常火热，人人都想要一个独属于自己的“公司”。

所谓一人公司不是所有的事情全都自己处理，而是自己统管全局，让各个 Agent 担任部门经理，员工等角色，相当于把工作外包给许多 Agent 干。

这是一个很好的想法！如今的大模型能力已经非常强了，在大多数情况下比人工完成的更好更合理（前提是把任务说明清楚），因为如此，所以一人公司的概念才能得到广泛地传播。

对于一个项目，使用串行的工作流在很多时候还真不是太好。其一，一个 Agent 的上下文有限，无法管理不同角色的任务和职责；其二，尽管可以在一个项目下开启多个会话用于执行不同任务，但是一直在会话中换来换去，容易干扰思路，并且两个会话之间的信息交流并不方便；其三，在一个 Agent 中一般只能使用本家的模型，不好发挥不同模型的优势。

采用 OpenBot 就能很好地解决上述痛点。

OpenBot 中可以创建适合具体任务的助手（员工），并可以把不同助手拉到一个具体的频道（公司），以便在频道中共同完成你安排的任务。

![OpenBot 项目的 github 页面](https://raw.githubusercontent.com/kosmigen/picgo-pictures/master/20261128114319579.png)

这个项目很活跃，几乎每天都会进行更新维护，可以放心入手！

安装 OpenBot 后登陆自己可以提供的大模型，需要使用哪家的模型就登陆哪家的。

然后就可以创建助手，每个助手有自己的颜色、名字、系统提示词和模型选择，也就是你可以自己定制这个助手是用来干嘛的。

![新建助手页面](https://raw.githubusercontent.com/kosmigen/picgo-pictures/master/20261128115728158.png)

自己需要的助手新建完成后，就可以创建频道了，很简单，左侧的加号点击选择“新建频道”即可，在创建频道时就可以把助手放进去，也可以后续进行添加。助手和频道又可以放在文件夹中，方便管理。

完成后，就可以在频道中指定某个助手完成任务或者让他们进行讨论得出方案。

每个频道中有一个默认的助手作为这个频道的“总管”，我建议单独弄一个助手作为总管，不指定的话，会默认使用排名第一的助手作为“总管”。

OpenBot 中还有工作流的功能，但是我暂时还没有用过，后续使用了对应功能再写一篇博客介绍一下。
