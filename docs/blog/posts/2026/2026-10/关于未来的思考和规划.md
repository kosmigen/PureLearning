# 关于未来的思考和规划

现在这个时代，给人一种强烈的焦虑感，迫使着人们浮躁。

<!-- more -->

## GPT 横空出世

2018 年 OpenAI 发布了他们的第一款 GPT，当时我才高中毕业。

大学期间我才真正认识到 AI 的强大，当时全网都在热烈讨论 GPT 的对话功能，软件开发者对于其可以替代的他们的评论嗤之以鼻，可惜的是在 25 年 Claude Code 发布，从此以后 AI Agent 就一发不可收拾，不断地提出更优秀的机制，使得 Agent 的功能得到迅速发展，今天 2026 年 11 月 6 日，可以说大部分使用电脑的任务，这些 Agent 都能完成的很好！当然包括 coding 。

这是最好的时代，这是最坏的时代。

## Software “已死”

我本科读的是软件工程专业，研究生仍然读的软件工程专业，都在说“软件已死”，这次看来也不是虚假的了。

但自怨自艾是不可能解决问题的，我们要在绝望之中寻觅一丝可能的救赎。

## 还能做什么？

如今的就业市场没有实习根本不看简历，所以如果想在外面的企业中上班，实习是必不可少的。

当然，也可以选择到央国企，在拥有应届生身份时去应聘，难度是最低的，性价比是最高的。

Java 相关技术栈还是重要，同时可以扩展自己的技术能力，比如 Python 。

重要的是有相关的项目，才能找实习，从而找工作。我还有知识星球中**沉默王二**的项目，先全部拉下来，然后看看，学习学习。

小圆考过了养老的一个证书，她不是很想去养老院，我倒是觉得这个方向很不错，以后有时间叫她辅导辅导我，让我也去考过，也算是多一条路。
