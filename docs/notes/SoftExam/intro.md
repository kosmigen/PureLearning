# 软考概述

参考资料：

- [软件设计师——CTO说](https://github.com/xiaomabenten/software_designer/tree/main)

软考全称为“计算机技术与软件专业技术资格（水平）考试”，一年有两次考试机会，分别在上半年的 5 月下旬和下半年的 10 月下旬。

资格共有初、中、高级之分，每个级别中包含多种技术分类，比如中级中包含软件设计师、网络工程师、信息安全工程师等等，根据自己的需求进行对应考试的准备。我在这里学习的是软件设计师。

我的计划是在研一下学期去考中级软件设计师，研究生毕业前考过高级系统架构师。

先通过《软件设计师考试 32 小时通关》这本书对整体的知识分布有个认知，学习过后，先做真题，后续还有时间和精力再去看额外的教辅资料。
