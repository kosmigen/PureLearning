## 如何使用示例

完整示例会标明文件名，并给出输出或预期现象。以 `Main.java` 为例：

```sh
javac -encoding UTF-8 Main.java
java Main
```

代码中的路径、输入和类型可以自行修改。先运行原始示例，再改变一个条件观察结果，例如把合法下标改成越界下标，或把可修改集合换成不可修改集合。

## 学完之后

尝试编写一个命令行学习记录程序：使用对象表示记录，使用集合管理数据，通过异常处理校验输入，最后将记录保存到文件。再进入[进阶](../advanced/index.md)，学习并发、网络和运行时机制。
