# Java 进阶

进阶部分介绍 Java 的语言机制、网络通信、并发执行与运行时原理。阅读前建议掌握[核心知识](../basics/overview.md)，尤其是接口、泛型、异常和 IO。

## 本部分内容

| 专题 | 需要掌握的问题 |
| --- | --- |
| [函数式编程](functional/index.md) | 如何把行为作为参数，使用流水线处理数据？ |
| [反射与注解](reflection-annotations/index.md) | 如何在运行时检查类型、读取元数据并调用方法？ |
| [网络编程](networking/index.md) | 如何通过 Socket 和 HTTP 交换数据，设置协议边界与超时？ |
| [并发编程](concurrency/index.md) | 如何执行多个任务，保护共享状态并组合异步结果？ |
| [JVM](jvm/index.md) | 字节码如何执行，类和对象如何被加载与管理？ |

## 阅读顺序

函数式编程与反射可以分别阅读。网络示例会使用线程或执行器，可以结合并发章节理解任务执行方式。JVM 章节则帮助解释类加载、内存和性能方面的问题。

示例以 JDK 21 为基准。线程调度、网络时延和内存占用可能随环境变化；对应章节会区分固定输出与需要观察的现象。

## 综合练习

为学习记录程序增加本地 HTTP 查询接口，使用独立任务计算学习统计信息，并对共享数据的修改方式作出说明。遇到运行问题时，尝试通过线程信息或运行日志定位原因。
