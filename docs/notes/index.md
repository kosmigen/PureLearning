## 怎么使用这一部分

**计算机基础。** 学到一定量之后，卡住你的往往不再是语言，而是语言背后的东西：为什么这个数据结构更快、进程和线程到底差在哪、一次请求在网络里走了多远。这些概念不依赖某一门语言，值得单独整理并长期复查。

**AI 原理。** 这里整理机器学习、神经网络和生成式 AI 的概念与方法；具体的语言用法放在对应语言栏目中。

**工程笔记贯穿全程。** 测试、类型、打包、可复现性——这些不属于某个阶段，而是每一段路上都会反复遇到的问题，所以单独记，按问题归档。

## 笔记怎么写

同一件事记两遍是有意的：**「文章」里放写完的、给别人看的**，**「笔记」里放给自己查的**。笔记不追求完整，只要求下次翻到时能立刻接上。

每篇笔记尽量交代清楚四件事：

| 要交代的 | 说明 |
| --- | --- |
| 问题是怎么来的 | 什么场景下遇到、为什么值得记 |
| 结论和依据 | 原理、成立条件、代价或复杂度 |
| 验证方式 | 用什么代码或实验确认了它 |
| 边界 | 什么情况下这个结论不成立 |

只写结论的笔记，三个月后和搜索引擎的结果没有区别。
